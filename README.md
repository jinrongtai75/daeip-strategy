# 대입전략판 (2027학년도 수시 논술)

9개 논술 전형의 **학과별 모집인원 · 원서/서류/고사 일정 · 고사장 · 경쟁률**을
한 화면에서 비교하는 정적 페이지입니다.

**주소:** https://jinrongtai75.github.io/daeip-strategy/

## 담고 있는 것

- **학과별 논술 모집인원 132개** — 7개 대학 9개 전형, 각 대학 홈페이지 배포
  2027학년도 수시 모집요강 PDF 원문 대조
- **전형별 일정** — 접수 시작·마감, 서류 마감, 고사일·교시, 고사장 발표일, 합격 발표
- **고사일 충돌 매트릭스** — 같은 날 전형의 교시별 병행 가능 여부 (이동여유 60분 기준)
- **학과별 경쟁률** — 전년도(2026학년도) 실적. 한양대는 최저충족률·실질경쟁률·논술평균까지
- **수능최저 기준** — 대학별 규칙(탐구 반영 방식·영어 등급 통합·수학 의무반영 등) 반영
- **11/21 분기** — 고려대 학과 선택(오전조/오후조)이 경희대 응시 가능 여부를 결정하는 구조

## 성적은 저장되지 않습니다

이 페이지는 공개 주소이므로 **성적 데이터를 포함하지 않습니다.**
화면에서 등급을 입력하면 그 값은 **접속한 기기의 브라우저(localStorage)에만** 저장되며
서버로 전송되지 않습니다. 다른 사람이 같은 주소를 열어도 보이지 않습니다.

## 주의

- 모집요강은 **정정공고**가 날 수 있습니다. 최종 확인은 각 대학 입학처 공고를 따르세요.
- 경쟁률은 **전년도 실적**입니다. 2027학년도에 모집인원이 줄어든 학과는 실제 경쟁률이 더 오릅니다.
- 고려대 논술고사 종료시각, 경희대 입실 마감시각 등 **요강에 없는 항목은 추정치**이며
  화면에 별도 표시했습니다. 일정이 촉박한 조합은 입학처 확인이 필요합니다.
